# Арлан — банк знаний и идей

Публичное пространство команды для идей, знаний, предложений, проблем, фотографий и материалов.

## Быстрый вход

- [Открыть Wiki](https://github.com/merushka/Arlan/wiki)
- [Добавить идею](https://github.com/merushka/Arlan/issues/new?template=idea.yml)
- [Посмотреть все предложения](https://github.com/merushka/Arlan/issues)

## Как работать

1. Быстрые предложения добавляйте через форму **Добавить идею**.
2. Проверенные знания и решения переносите в Wiki.
3. Прикладывайте фотографии перетаскиванием в редактор GitHub.
4. Не публикуйте пароли, персональные данные и закрытые документы: репозиторий публичный.
5. Codex может читать репозиторий и Wiki как Git-источники.
